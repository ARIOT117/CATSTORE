# CATSTORE

Sitio estático de CATSTORE, preparado como repositorio independiente para Vercel.

## Contenido

- `index.html`: inicio.
- `productos.html`: catálogo.
- `nosotros.html`: información del proyecto.
- `login.html`: formulario de demostración.
- `CSS/`, `JS/` e `Imagenes/`: estilos, comportamiento e imágenes.

## Publicación en Vercel

1. Sube este repositorio a GitHub.
2. En Vercel, crea un proyecto e importa el repositorio.
3. Selecciona **Other** como framework, deja vacío el comando de compilación y usa la raíz del repositorio (`.`) como directorio de salida.
4. Despliega el proyecto.

El formulario de inicio de sesión es solo una demostración en el navegador: no hay servidor ni autenticación real.
